# Clipboard history: recorded application filter

Mode: Operate. Narrow extension of the incumbent native Clipboard interface.

Preserve the family bronze/charcoal palette, local fonts, standard fields/buttons,
existing text/type controls and explicit clipboard actions. The task is retrieval
by an exact saved process name, not discovering installed or current applications.

One labelled application input and one clear-only-application button. State the
applied name, loaded count and native list/search scope. Empty/error/loading
states belong to the results region; reader and bundle keep their mount/drafts.
Names wrap in results on mobile. No new icons, cards, dialogs or i18n framework.

Visual verification: desktop 1280×1050 and mobile 390×844, fixture only; native
clipboard remains stopped. Author captures/evidence live outside the worktree.
The inherited DESIGN sidecar drift is reported without changing that artifact.
