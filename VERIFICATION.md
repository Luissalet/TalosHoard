# Talos verification

Verified on Windows with isolated synthetic histories. Original histories were not opened by the test servers.

- Product suite: 15 passed, including independent OFF defaults, saved state, native module APIs, Funes audio compatibility, strict switch values and retained external data locations.
- Retired services are excluded after merging discovery and saved restart overrides. A regression reproduced the old Argus restart command remaining active, then passed with the fix; the saved settings file stays unchanged.
- Streaming: the first SSE event arrives before the producer completes; disabling cancels a live stream before closing its engine. Media responses retain native streaming and range support.
- Shutdown: OFF intent persists before a deliberately blocked shutdown; the dashboard remains responsive.
- Actual stdio MCP: discovery of 93 tools, disabled call rejection, clipboard enable/call/disable and rejection after disable all passed. Discovery does not launch the server.
- Incorporated regression suites: Argus 64 passed (one slow test deselected), Echo 48, Funes 95, Cassandra 25, Disk 107 passed and one skipped. Argus was repeated with unhandled thread exceptions treated as errors after fixing its worker shutdown race.
- All seven native UI builds across Talos and Hermes completed. Talos screen, clipboard, activity, audio, services and disk pages were opened through the browser with synthetic/offline engines. Clipboard ran independently of screen capture.
- Desktop and mobile module controls use the canonical family theme, local fonts, generated family-style icons and the common Faustus control. The independent finish review records its precise scope separately.

- Audio echo clean-up, chapters and bench (28 Oct 2026): 51 new tests (echo and chapters 40, bench 11) plus the whole Funes suite (562 passed; four tests that still assumed the standalone repository layout, `test_cli` x2, `test_manifest` and `test_timeparse`, were adapted to Talos's root). Live on an isolated instance (private port, temporary data, all other modules OFF): `scribe_chapters` through `/api/agent/call` with the real global model wrote five chapters for a 20-minute Spanish meeting and answered from the store on the second call; `scribe_echo_check` listed and removed two echo lines; `scribe_bench` ran the music and silence cases with faster-whisper small on CPU (99 % found, 0 lines for silence, both inside their thresholds). A headless browser showed the chapters panel, five ticks on the waveform, the two new switches and the bench table; the full bench with the four cases was measured separately (see README).

- Scheduled SEO/GEO watch of public sites (28 Oct 2026): 31 new tests (`test_seo_watch.py`, `test_seo_api.py`: report parsing, drift, baseline, alerts once, failed audits, schedule, API, tools, notification privacy) and the Cassandra suite (218 passed; five tests that still looked for the standalone manifest and client folder, `test_copilot` x3, `test_job_incidents` and `test_manifest`, were adapted to Talos's root manifest, catalogue and `ui/` layout) plus `tests` (19). Live on an isolated instance (private port, temporary data) with a stand-in hub that answers `site_audit` because Vitruvius does not offer it yet: the real portfolio site was added with `sites_watch` and `seo_interval_h`, the scheduler ran the first audit by itself (baseline 78), `sites_seo_run` with a worse answer raised `cassandra.site.seo_drop` and `cassandra.site.seo_critical` on the hub (seen in the stand-in's log), an answer of "unknown tool" left a failed run with its cause and the last score kept, and a headless browser showed the score and change in the site row, the SEO y GEO block, the error text and the interval field, saving it and accepting the baseline.

- Differential test of the Funes absorption (28 Oct 2026): the last Funes commit before the move (run as its own server) and Talos's Activity and Audio modules answered the same 130 recorded calls to the 19 Activity and 16 Audio tools (argument errors, not-found, imports, transcription jobs, live recordings on one and two tracks, deletes) over data built by the old code. Through `/api/agent/call` and through `/legacy/funes/api/agent/call` all 130 traces were identical after masking ids, clock, ports and job ids, in three consecutive runs each; a deliberate regression in the note store was caught at its first call. Nothing was lost; the intended differences (modules inside one server, a single entry point, one optional argument and four tools added) are listed in `scripts/differential/funes_absorption/README.md`. Four helper tests (`tests/test_differential_funes.py`) cover the normaliser and the corpus.

- Differential test of the Screen, Clipboard, Services and Disk absorption (29 Oct 2026): the last commit of each old repository before the move (run as its own server) and Talos with only that module on answered the same recorded calls (85, 124, 148 and 123 cases) through both routes (`/api/agent/call` and `/<module>/api/agent/call`), with temporary data and no real capture. Each harness passed 3 consecutive runs; the negative control (`--mutate`) fails all eight harnesses at the case that exercises the broken behaviour. No divergence beyond the intended differences listed in the folder README was found, so nothing was lost. Method and numbers in `scripts/differential/module_absorption/RESULT.md`; helper tests in `tests/test_differential_modules.py`.

Hardware audio capture, GPU inference, live purchases, mail ingestion and destructive disk operations were not triggered in these checks. Existing engine tests and static tool parity preserve those capabilities; these checks do not claim a fresh live validation of every external provider or device.

Source commits and native tool inventory are recorded in `provenance/`. Data adoption only writes the central module-to-folder mapping, with every module OFF. Private preservation receipts are kept outside the public repository.
